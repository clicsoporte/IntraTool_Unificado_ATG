========================================================================
ESTÁNDAR DE DISEÑO RESPONSIVO PREMIUM - CLIC-TOOLS
========================================================================

Este documento establece la directriz técnica y visual para adaptar páginas
complejas, vistas con múltiples secciones (Tabs) y formularios extensos a
dispositivos móviles. Toda implementación futura de flujos responsivos
debe adherirse estrictamente a este estándar para asegurar una experiencia
de usuario de alta gama (Premium).

------------------------------------------------------------------------
1. PRINCIPIO FUNDAMENTAL: AISLAMIENTO DE VIEWPORT
------------------------------------------------------------------------
Las interfaces web responsivas tradicionales a menudo intentan comprimir
o reajustar cuadrículas tridimensionales (grids) y tablas anchas en
pantallas verticales estrechas. Esto causa desbordamiento horizontal (scrollbar
en la ventana principal), botones superpuestos y elementos estirados.

La directriz del proyecto es aislar los flujos complejos en su propia
ventana emergente móvil independiente. Todo formulario extenso o conjunto
de subsecciones de detalles en móviles se desplegará dentro de una:
  ==> HOJA DESPLIZABLE INFERIOR (BOTTOM SHEET DRAWER) <==

------------------------------------------------------------------------
2. ARQUITECTURA DE CONTENIDO Y NAVEGACIÓN
------------------------------------------------------------------------
Cuando se adapte un panel de control con múltiples pestañas (Tabs):

A. Menú de Pestañas Tradicional (Escritorio):
   - Se muestra solo en pantallas medianas y grandes (ej: "hidden md:block").
   - Utiliza la barra horizontal Radix/Shadcn tradicional.

B. Menú de Acceso Vertical (Móvil):
   - Se muestra solo en pantallas móviles (ej: "flex flex-col gap-3 md:hidden").
   - Se compone de una lista vertical de botones estilizados como tarjetas de
     acceso rápido:
     * Altura táctil cómoda: h-14
     * Bordes redondeados modernos: rounded-2xl
     * Fondo blanco con sombra difusa: bg-white border-slate-200/80 shadow-sm
     * Iconos con micro-backdrops: Contenedores pequeños (w-8 h-8 rounded-xl)
       con colores pastel muy suaves para dar dinamismo visual al menú.
     * Indicador direccional visual: "➔" alineado a la derecha.

C. Acciones y Triggers:
   - Al tocar un botón de sección móvil, se realizan simultáneamente dos acciones:
     1. Se actualiza el estado de la pestaña activa (setActiveTab).
     2. Se abre el panel inferior deslizable (setMobileSheetOpen(true)).

------------------------------------------------------------------------
3. ESPECIFICACIONES TÉCNICAS DEL BOTTOM SHEET DRAWER (PREMIUM)
------------------------------------------------------------------------
La hoja deslizable inferior (Sheet) en móviles debe ser de máxima calidad:

- Altura y Geometría:
  * Ocupación de pantalla: h-[92vh]
  * Bordes superiores redondeados pronunciados: rounded-t-[2rem]
  * Fondo: bg-slate-50
  * Borde superior fino: border-t border-slate-200

- Elementos de Interfaz Críticos:
  1. Indicador de Arrastro (Drag Handle):
     * Un elemento visual simple en el centro superior que indica que es deslizable.
     * Estilo: w-12 h-1.5 bg-slate-300 rounded-full mx-auto my-3 shrink-0
  2. Encabezado Fijo (Sticky Header):
     * Fondo blanco brillante (bg-white) y borde inferior para enmarcar el título.
     * Título con iconos descriptivos y descripción en texto pequeño con los datos
       del registro activo.
  3. Contenedor de Scroll Dedicado (Dedicated Scroll Area):
     * La sección interna de contenido debe tener scroll independiente:
       flex-1 overflow-y-auto px-4 py-4 pb-20
     * Esto previene que cualquier desbordamiento interno afecte a la
       página principal.

- Botón de Cierre (X) Ultra-Táctil Premium:
  * Ubicación: absolute right-4 top-4
  * Forma: Circular perfecta (rounded-full) con transición interactiva (active:scale-95)
  * Tamaño físico táctil óptimo: w-10 h-10
  * Fondo de contraste ultra-visible: bg-red-500 hover:bg-red-600 text-white shadow-md
  * Icono de cierre destacado: h-5 w-5 stroke-[2.5] (Icono Lucide X con trazo grueso)

------------------------------------------------------------------------
4. EJEMPLO DE IMPLEMENTACIÓN DRY (NEXT.JS / SHADCN)
------------------------------------------------------------------------
El uso de una función IIFE local permite declarar la estructura de las
pestañas una sola vez en el código (DRY), reutilizándola en ambos layouts:

```tsx
<Tabs value={activeTab} onValueChange={setActiveTab} className="w-full">
    {/* Desktop Tabs Header List */}
    <div className="hidden md:block">
        <TabsList>
            <TabsTrigger value="info">Información</TabsTrigger>
        </TabsList>
    </div>

    {/* Mobile Vertical Menu (Stacked Cards) */}
    <div className="flex flex-col gap-3 md:hidden">
        <Button onClick={() => { setActiveTab('info'); setMobileSheetOpen(true); }} className="...">
            <span>📋 Información</span> <span>➔</span>
        </Button>
    </div>

    {/* IIFE para encapsular el contenido sin duplicar código */}
    {(() => {
        const renderTabsContent = () => (
            <>
                <TabsContent value="info">
                    {/* Contenido Complejo / Formularios / Tablas */}
                </TabsContent>
            </>
        );

        return (
            <>
                {/* Escritorio Inline */}
                <div className="hidden md:block">
                    {renderTabsContent()}
                </div>

                {/* Móvil Bottom Sheet */}
                <Sheet open={mobileSheetOpen} onOpenChange={setMobileSheetOpen}>
                    <SheetContent side="bottom" className="h-[92vh] rounded-t-[2rem] bg-slate-50 p-0 overflow-hidden flex flex-col">
                        <div className="w-12 h-1.5 bg-slate-300 rounded-full mx-auto my-3 shrink-0" />
                        <SheetHeader className="px-6 pb-4 border-b bg-white">
                            <SheetTitle>Información</SheetTitle>
                        </SheetHeader>
                        <div className="flex-1 overflow-y-auto px-4 py-4 pb-20">
                            <Tabs value={activeTab} className="w-full">
                                {renderTabsContent()}
                            </Tabs>
                        </div>
                    </SheetContent>
                </Sheet>
            </>
        );
    })()}
</Tabs>
```

Toda nueva vista compleja agregada al sistema que requiera navegación responsiva
debe replicar este patrón exacto de diseño.
