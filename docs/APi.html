📘 Manual de Reconstrucción Completa del Sistema

Servidor de API · Bot de Telegram · Infraestructura Segura
Versión 3.0 · Agosto 2026

Este manual cubre todos los componentes para reconstruir desde cero el servidor de API y bot de Telegram, incluyendo:
  • Servidor local (Next.js) en puertos 9003 (producción) y 9001 (desarrollo)
  • pfSense como firewall y concentrador VPN
  • VPS AWS Lightsail como proxy inverso y puente seguro
  • WireGuard para comunicación entre VPS, LAN y celulares
  • IPsec Mobile Clients como plan B para celulares
  • Nginx con filtrado de IPs de Telegram y SSL

6. Nginx - Proxy Inverso y SSL

6.1 Producción (api.industriasgarend.com)

sudo nano /etc/nginx/sites-available/api.industriasgarend.com
server {
    listen 80;
    server_name api.industriasgarend.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl;
    server_name api.industriasgarend.com;

    ssl_certificate /etc/letsencrypt/live/api.industriasgarend.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.industriasgarend.com/privkey.pem;
    include /etc/letsencrypt/options-ssl-nginx.conf;
    ssl_dhparam /etc/letsencrypt/ssl-dhparams.pem;

    location / {
        return 403;
    }

    location /api/telegram/webhook {
        allow 91.108.4.0/22;
        allow 91.108.8.0/22;
        allow 91.108.12.0/22;
        allow 91.108.16.0/22;
        allow 91.108.56.0/22;
        allow 149.154.160.0/20;
        deny all;

        proxy_pass http://192.168.1.14:9003;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

6.3 Obtener certificados SSL

# Para cada dominio, primero crear configuración temporal HTTP
sudo tee /etc/nginx/sites-available/api.industriasgarend.com > /dev/null << 'EOF'
server { listen 80; server_name api.industriasgarend.com; location / { return 200 "OK"; } }
EOF
sudo ln -s /etc/nginx/sites-available/api.industriasgarend.com /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d api.industriasgarend.com

# Repetir para dev-api.industriasgarend.com

# Luego restaurar configuraciones seguras completas
sudo nginx -t && sudo systemctl reload nginx

10. Solución de Problemas

SíntomaCausa probableSolución
Mensajes no llegan al bot MTU incorrecto Verificar ip link show wg0 | grep mtu → 1420
502 Bad Gateway App no corriendo Verificar netstat -ano | findstr "9001 9003"
Celular no conecta WireGuard IP no está en alias Agregar 201.191.0.0/16 al alias Kolbi
VPN se cierra al cerrar app Optimización de batería Desactivar ahorro de batería para WireGuard
No conecta en WiFi empresa AllowedIPs incorrecto Usar 192.168.1.14/32 en vez de 0.0.0.0/0
IPsec no conecta Puertos cerrados Abrir UDP 500 y 4500 en WAN
